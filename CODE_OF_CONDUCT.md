# Code of conduct

Badger SQL Migrate is a place to build a good tool together. Everyone taking part (in issues, pull requests, discussions and anywhere else on behalf of the project) is expected to:

- be respectful and assume good intent, including when you disagree;
- keep feedback about the work, never about the person;
- welcome newcomers and questions at every level of experience;
- respect people's privacy: don't share anyone's personal information, credentials or server details.

Harassment, insults, discriminatory language, sexual content and personal attacks aren't acceptable.

## Enforcement

Report problems to [support@lonebadger.tech](mailto:support@lonebadger.tech) with "Conduct" in the subject. Reports are handled confidentially. Maintainers may edit or remove comments, and may warn, temporarily block or permanently ban anyone who breaks these rules.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
